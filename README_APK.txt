CARROSSEL STUDIO PARA ANDROID

O APK de testes fica em:
android/app/build/outputs/apk/debug/app-debug.apk

INSTALAÇÃO
1. Copie o APK para o celular Android.
2. Abra o arquivo no celular.
3. Autorize a instalação de aplicativos desconhecidos quando solicitado.
4. Instale e abra o Carrossel Studio.

Os dados ficam armazenados somente no aplicativo. Use "Dados e backup" para
compartilhar uma cópia das configurações.

Este é um APK de testes assinado automaticamente pelo Android. Para publicação
na Google Play será necessário gerar uma chave definitiva e um arquivo AAB.

COMPILAÇÃO PELO GITHUB
O arquivo .github/workflows/build-apk.yml gera o APK automaticamente a cada
envio para as branches main ou master. O APK aparece nos artefatos da execução
com o nome "carrossel-studio-apk".
